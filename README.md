# 大地のつくり 3D土地模型（chisou3d）

小学6年理科「土地のつくりと変化（大地のつくりと働き）」の学習用ツールです。
**国土地理院の地形データ**と**ボーリング資料**から、学校のまわり（いまは長津田小学校から半径1km）の
土地を、**地下の地層まで見える3D模型**にします。

- 指やマウスで、ぐるっと回す・近づく／はなれる・ずらす（Googleマップのような操作）
- 地図の上の🔍の旗（ボーリングの場所）をタップ → その場所の**柱状図**（地層の柱の図）が出る
- **地層をはがす**：上の層を1枚ずつはがして、谷の両側に同じ地層が続いているのを見る
- **断面図を作成**：2か所をタップすると、その線で模型を切って切り口を見る＋下に断面図が出る
- **予想をかく → 答え合わせ**：断面図に、子どもがペンで「地層のつながりの予想」をかき、
  「模型の地層を見る」で推定した地層と重ねてくらべる
- **気づきメモ**：模型の上に付せんのようにメモを置ける（書き出して先生の端末に集められる）

## 使い方の説明はどこにある？

- 画面右上の **「？ 使い方」** … はじめて開いたときにも自動で出ます（タブで「地層を見る」「断面と予想」「気づきメモ」「先生向け」）
- **ボタンの上にマウスをのせる**と、そのボタンの説明が出ます
- 画面右上の **「📚 根拠」**（または画面下の「くわしく」）… この模型が何をもとに作られているか、元の資料へのリンク

## 開き方

**いちばんかんたん**：`dist/3D土地模型_長津田小学校のまわり.html` を1つだけ配って、ダブルクリックで開く。
（見た目・プログラム・設定が全部この1ファイルに入っています。`python3 build_single.py` で作り直せます）

フォルダ版を使うとき（ZIPは必ず「すべて展開」してから）：

`chisou3d` フォルダをまるごとパソコン（Chromebook可）に置いて、`index.html` をChromeで開きます。
インターネットにつながっている必要があります（地形・地図は開くたびに国土地理院から読み込みます）。

> GitHub Pages を使うと、URLを配るだけで子どもの端末から開けるようにもできます。

## 使い方のヒント（授業の流れの例）

1. **「地下の地層をかくす（予想するとき用）」にチェック**して、地形とボーリングの柱だけを見せる
2. 「✂️ 断面図を作成」で、恩田川をはさんで学校と向こうの丘を通る線を切る
   （ボーリングの旗をタップすると、そのボーリングを通る線になる）
3. 断面図に、ボーリングの柱を手がかりに**地層のつながりをペンで予想**してかく（📷保存で画像にできる）
4. チェックを外し、「模型の地層を見る（答え合わせ）」や「地層をはがす」で、予想とくらべる
5. 気づいたことを「📝 気づきメモ」で模型の上に残す

## 画面のボタン

| 場所 | できること |
|---|---|
| 左のパネル | 地図の種類／高さの強調（×1が本当の高さ）／地面の透明度／地層をはがす／表示の切りかえ／見る向き／凡例 |
| 下のボタン | 👆見る・✂️断面図を作成・📝気づきメモ・（先生モード）➕ボーリング追加 |
| 右上の方位 | 北の向き。タップで北を上にもどす |

## いま入っているボーリング資料

**国土地盤情報データベース**（一般財団法人国土地盤情報センター）の柱状図のうち、
長津田小学校から**半径2km以内の240本**（2026年9月取得）を `sites/nagatsuta.js` に入れてあります。
（そのうち半径1km以内は108本。学校の増築工事のときの調査も入っています）

- 層（盛土・沖積層・ローム層…）は、資料の土の名前から自動で当てはめたものです
  （例：砂礫→れき、土丹・固結シルト→泥岩、凝灰質粘土・黒ボク→ローム層、有機質土→沖積層）
- 模型では「ねんど→砂→れき→泥岩」の順に重なっている、と単純化して地層の面を推定しています。
  実際の地層は、砂とねんどが何回もくり返していたりするので、ボーリングとボーリングの間は「推定」です
- 位置が書かれていないファイル・古い座標（日本測地系）で大きくずれていたものは、データベースの地図の点の位置を使っています
- 国土地盤情報データベースの利用規約により、地盤情報を複製するときは出典を表示します（画面の「📚根拠」、各ボーリングの出典欄）

## 本物のボーリング資料を入れる（先生用）

いまは**仮のデータ**（考え方を示すための架空のボーリング）が表示されています。オレンジ色の旗が仮データです。

資料の入手先の例：
- 横浜市「[地盤View](https://wmap.city.yokohama.lg.jp/)」（よこはまっぷ → 地盤View）…公共工事のボーリング柱状図
- 国土地盤情報検索サイト「[KuniJiban](https://www.kunijiban.pwri.go.jp/)」

### 方法0：柱状図XMLを読み込む（いちばん速い）

1. [国土地盤情報データベース](https://publicweb.ngic.or.jp/public/publicweb.php) で学校のまわりのボーリングをさがし、
   **XML（ボーリング交換用データ）**をダウンロードする（ZIPなら展開しておく）
2. 模型の「先生モード」→ **「📄 柱状図XMLを読み込む」** → XMLファイルを選ぶ（何本でもまとめて選べます）
3. 場所（緯度経度）・孔口標高・地層・N値が自動で入ります。
   **層の当てはめ（例：砂礫→れき、土丹→泥岩、N値4以下のシルト・粘土→沖積層）は自動**なので、
   出てくる一覧で確認し、ちがっていれば「当てはめを直す」で変えてください。

### 方法A：画面から入力する（かんたん）

1. 左パネルいちばん下の「先生モード」にチェック
2. 下の「➕ ボーリング追加」→ 地図の上でボーリングの場所をタップ
3. 名前・孔口標高（資料にある地面の標高。空欄なら地図の標高を使う）・出典を入れ、
   **上から順に**「下の面の深さ」「層」「土の名前」「N値」を入力して保存

入力したデータは**その端末のブラウザの中**に保存されます。ほかの端末でも使うには：
- 「データを書き出す」→「ファイルに保存」→ ほかの端末で「データを読み込む」、または
- 書き出した文字の `boreholes` の部分を `sites/nagatsuta.js` の `boreholes: [ ... ]` に貼り付ける
  （こうすると、全員の画面に最初から出るようになります）

### 方法B：設定ファイルに直接書く

`sites/nagatsuta.js` の `boreholes` に、書き方の例にならって書き足します。
`layer` には次のどれかを書きます（資料の土の名前を、いちばん近いものに当てはめる）：

| layer | 層 | 資料での名前の例 |
|---|---|---|
| `fill` | 盛土 | 盛土・埋土 |
| `alluvium` | 川が運んだ土砂の層（沖積層） | 沖積層・シルト・腐植土（谷底のやわらかい層） |
| `loam` | 火山灰の層（関東ローム層） | ローム・関東ローム・凝灰質粘土 |
| `clay` | ねんどの層 | 粘土・シルト（丘の下の固い層） |
| `sand` | 砂の層 | 砂・細砂・シルト質砂 |
| `gravel` | れきの層 | れき・砂れき・玉石 |
| `mudstone` | 泥岩の層（土丹） | 泥岩・土丹・固結シルト |

本物の資料が集まったら、先生モードの「仮データを表示」を外すか、
`sites/nagatsuta.js` の `sample.enabled` を `false` にしてください。

### 層の名前・色を変えたいとき

`sites/nagatsuta.js` の `layers` を編集します。`mode` の意味：
- `cover` … 地面をおおう層（地形に沿ってのる。関東ローム層など）
- `valley` … 谷の底だけにたまる層（沖積層など）
- `surface` … 広く積み重なった地層。谷の所は川にけずられている

## ほかの場所の模型をつくる（例：篠原西小学校）

### 方法1：画面だけでつくる（Claudeを使わない）
1. 先生モード →「**＋ 新しい場所の模型をつくる**」→ 学校名で「🔍 場所をさがす」（または地理院地図で右クリックして緯度・経度を貼り付け）→ 半径をえらんで「この場所でつくる」
   → 地形・地図・川・目印（駅・学校・公園・公共施設）が自動で入ります
2. ボーリング資料：「？使い方」の「**新しい場所**」タブにある **「📥 柱状図あつめ」ボタン**をお気に入りバーにドラッグして登録
3. [国土地盤情報データベース](https://publicweb.ngic.or.jp/public/publicweb.php) →「閲覧」→ 学校のあたりを表示 → お気に入りの「📥 柱状図あつめ」を押す
   → 半径内の柱状図が1本ずつ集まり「柱状図まとめ_○本.json」がダウンロードされる（200本で約10分）
4. 模型の先生モード →「📄 柱状図XMLを読み込む」→ そのファイルを選ぶ → 層の当てはめの一覧を確認

※ 作った場所・資料は**その端末のブラウザの中**に保存されます。ほかの端末へは「データを書き出す／読み込む」で。

### 方法2：Claude（Claude Code）に頼む
「**篠原西小学校の周辺の3D模型を作って**」と頼むと、スキル `.claude/skills/chisou3d-site/SKILL.md` の手順で、
データを集めて `sites/<id>.js` と1ファイル版を作ります（全員の画面に最初から入る形）。
Claude の作業環境の Network access に `publicweb.ngic.or.jp` と `cyberjapandata.gsi.go.jp` が必要です。

### 方法3：道具を自分で動かす（パソコンにPythonとNode.jsがある場合）
```
pip install mapbox-vector-tile playwright && npx playwright install chromium
python3 tools/make_site.py --id shinoharanishi --name 篠原西小学校 --lat 35.501991 --lon 139.614675 --radius 3000
node tools/check_site.js shinoharanishi   # 画面の写真で確認
```

| 道具 | やること |
|---|---|
| `tools/make_site.py` | ボーリング（国土地盤情報データベース）と目印（国土地理院）を集めて `sites/<id>.js` をつくる／`--update` で取り直す |
| `tools/parse_xml.js` | 柱状図XMLを模型の形に変換（アプリと同じ `js/boringxml.js` を使う） |
| `tools/site_template.js` | 新しい場所の設定のひな形（層の名前・色・説明など） |
| `tools/check_site.js` | 本物のデータで模型を開いて写真を撮る（確認用） |
| `build_single.py` | 1ファイル版（`dist/`）をつくる |

**注意**：国土地盤情報データベースは、短い時間にたくさん取ると一時的に接続を切られます。道具もブックマークレットも、1本ごとに間をあけています。

## 地下の地層の推定について（しくみ）

- 地形：国土地理院の標高タイル（5mメッシュ、無い所は10mメッシュ）
- 地層の境目の高さ：ボーリング資料の境目の標高から、「ゆるやかなかたむきの平面」＋「近いボーリングほど強く効く補正（逆距離加重）」で面を広げ、
  地形より上になる所は「川にけずられた」として切り取ります
- 沖積層は、ボーリングで見つかった谷底の高さより低い所だけにたまるように計算します

あくまで**限られたボーリング資料からの推定**です。ボーリングが少ない所ほど、実際とちがう可能性があります
（それ自体が「本当はどうなっているんだろう？」と考えるきっかけになります）。

## ファイル構成

```
chisou3d/
├── index.html        画面
├── css/style.css     見た目
├── js/geo.js         緯度経度と模型の座標の変換、地理院タイルの読み込み
├── js/geology.js     ボーリング資料から地層の広がりを推定
├── js/section.js     断面図（予想をかく・答え合わせ）
├── js/boringxml.js   柱状図XML（ボーリング交換用データ）の読み込み
├── js/mvt.js         地理院のベクトルタイルから目印（駅・学校など）を読む
├── js/ngic_bookmarklet.js 「📥 柱状図あつめ」ブックマークレット
├── tools/            データ集めの道具（make_site.py など）
├── js/app.js         3D模型の本体・操作
├── js/help.js        ボタンのヒント・使い方ガイド・根拠（出典）
├── sites/sites.js    場所の一覧
├── sites/nagatsuta.js 長津田小学校版の設定（層・ボーリング資料・仮データ）
├── build_single.py   1ファイル版をつくるスクリプト
├── dist/             1ファイル版（配布・お試し用）
└── lib/              three.js（3D表示ライブラリ, MITライセンス）
```

出典：国土地理院（地理院タイル・標高タイル）
