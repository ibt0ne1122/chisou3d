🏫 自分の学校のまわりで、3D土地模型を作る

6年理科「大地のつくり」で使う3D土地模型を、先生が自分の学校の地域で作るための手順です。上から順に、リンクを開きながら進めてください。プログラムを書く必要はありません。

手順（全部で30分〜1時間くらい）
  1. 模型の画面を開いて「先生モード」にする
  2. 学校の場所（緯度・経度）を調べる　…地理院地図
  3. 新しい場所の模型をつくる　…地形・地図・川は自動
  4. ボーリング資料（柱状図）を集める　…国土地盤情報データベース
  5. 柱状図を模型に読み込む
  6. 授業で見やすく整える
  7. 保存する・ほかの端末や子どもに配る
  8. 困ったとき
  9. 問い合わせ・データの送り先
用意するもの：インターネットにつながるパソコン（Edge か Chrome）がいちばん楽です。iPad でも作れますが、ボーリング資料をまとめて集める方法（手順4のB）はパソコンだけです。

1模型の画面を開いて「先生モード」にする

🧊 3D土地模型を開く ↗🏠 入り口（場所えらび）↗

  1. どの学校の模型でもよいので開きます（はじめは長津田小学校のまわりが開きます）。
  2. 左上の ☰ でパネルを開き、いちばん下の 先生モード にチェックを入れます。
  3. チェックのすぐ下に、先生用のボタン（📄 柱状図XMLを読み込む・＋ 新しい場所の模型をつくる など）が出ます。

※ 先生モードは、子どもに配る画面には出ません。

2学校の場所（緯度・経度）を調べる

緯度・経度（いど・けいど）＝地球の上の場所を表す2つの数字。たとえば長津田小は「35.530280, 139.490678」です。

🗾 地理院地図を開く ↗
https://maps.gsi.go.jp/

  1. 左上の検索らんに学校名（または住所）を入れて、学校の場所を表示します。
  2. 模型のまん中にしたい所（ふつうは校舎）で、パソコンは右クリック、iPad は長押しします。
  3. 出てきた画面の上の方にある 「35.xxxxxx,139.xxxxxx」 のような数字（緯度・経度）をコピーします。
手順3の画面の 🔍 場所をさがす に学校名を入れるだけでも、だいたいの場所が入ります（国土地理院の住所検索を使います）。中心をきっちり決めたいときは、地理院地図でコピーした数字を使ってください。

3新しい場所の模型をつくる

  1. 先生モードのボタンの ＋ 新しい場所の模型をつくる を押します。
  2. 学校名を入れ、「緯度・経度をまとめて貼り付け」に、手順2でコピーした数字を貼ります（緯度・経度のらんに自動で入ります）。
  3. 範囲（半径）をえらびます。はじめは 1km がおすすめです（2km四方の模型になります）。
  4. この場所でつくる を押します。

これだけで、国土地理院の地形（標高）・地図・航空写真・川・目印（駅・学校・公園など）が自動で入った模型ができます。

この時点では、地面の下の地層は「仮」です。手順4・5でボーリング資料を入れると、本物の資料から地層が推定されます。

4ボーリング資料（柱状図）を集める

ボーリング＝工事の前に地面に細い穴をほって、どんな土が何mの深さにあるかを調べたもの。その記録の図が「柱状図（ちゅうじょうず）」です。全国の公共工事の柱状図が、インターネットで公開されています。

🗾 国土地盤情報データベースを開く ↗
https://publicweb.ngic.or.jp/public/publicweb.php

開いたら、利用規約を読んで 「閲覧」 を押し、地図を学校のあたりまで動かします。地図の上の印が、ボーリングをした場所です。

A．1本ずつ集める（かんたん・iPad でもできる）

  1. 地図のボーリングの印を押します。
  2. 出てきた画面で 「XML」（ボーリング交換用データ）をダウンロードします。
  3. 使いたい柱の数だけくり返します（学校の近く・丘の上・谷の中など、高さのちがう所から 10本くらい あると、地層の重なりが分かりやすくなります）。

B．まわりの柱をまとめて集める（パソコン向け・おすすめ）

  1. 下の黄色いボタン 「📥 柱状図あつめ」 を、マウスでつかんで、ブラウザのお気に入りバーに落とします（1回だけでOK）。
    お気に入りバーが見えない・ドラッグできないとき
    • お気に入りバーを出す：Edge・Chrome とも Ctrl＋Shift＋B
    • ドラッグできないときは 📋 コピー を押し、お気に入りを新しく作って、その「URL」のらんに貼り付けます（名前は「柱状図あつめ」など）。
  2. 国土地盤情報データベースの「閲覧」の地図を開いたまま、お気に入りの 「📥 柱状図あつめ」 を押します。
  3. 「模型の中心の緯度,経度」と「半径」を聞かれます。手順2の数字と、手順3でえらんだ半径（m）を入れて OK。
  4. まわりの柱状図を、間をあけながら1本ずつ集めます（200本で10分くらい。そのまま待ちます）。
  5. 終わると 「柱状図まとめ_○本.json」 というファイルがダウンロードされます。
データベースに負担をかけないよう、集める間かくを空けています。何度も続けて動かすと「access interval is too short」と出て、しばらく使えなくなることがあります。そのときは時間をおいてからにしてください。
ほかの柱状図の入手先（横浜市・国の工事）
  • 横浜市「よこはまっぷ」地盤View ↗：横浜市の公共工事の柱状図。画面で見て、模型の柱とくらべる資料に使えます（この模型には読み込めない形式です）。
  • 国土地盤情報検索サイト KuniJiban ↗：国の工事の柱状図。XMLがダウンロードできるものは、そのまま読み込めます。

5柱状図を模型に読み込む

  1. 手順3で作った模型を開き、先生モードの 📄 柱状図XMLを読み込む を押します。
  2. ダウンロードした XML（何本でもまとめてえらべます）か、「柱状図まとめ_○本.json」 をえらびます。
  3. 読み込むと、資料の土の名前 → 模型の層（盛土・ローム層・沖積層・ねんど・砂・れき・泥岩）の当てはめの一覧が出ます。
  4. ちがうと思う所は、一覧の ✏️ 当てはめを直す で変えます（あとから直すときは、柱をタップして開く画面の ✏️ 編集）。
自動の当てはめのきまり（例）模型の層
盛土・埋土・表土人が盛った土
ローム・火山灰・凝灰質〜・軽石関東ローム層（火山灰）
腐植土・有機質〜、N値4以下のやわらかいシルト・粘土沖積層（谷にたまった新しい層）
泥岩・土丹・固結〜泥岩
そのほかは、名前のいちばん後ろの土で決める（砂礫→れき、礫混じり砂→砂、砂質シルト→シルト）れき・砂・ねんど

N値＝重りを落として、土に棒が30cmささるまでの回数。小さいほどやわらかい土。

6授業で見やすく整える

  • 柱の色と名前を教科書の言葉に：☰パネルの「ボーリングの柱の色分け」で 「先生の仲間分けで」 → ✏️ 仲間分けを決める → 見本の 「📘 教科書どおり（れき・砂・どろ・火山灰・泥岩）」 → 決める。資料の名前がたくさんあっても、教科書の仲間にまとまります。
  • 柱の名前をかくしてピンだけに：☰パネルの「柱の名前（🔍の名札）」で 「ピン（●）だけ出す」。
  • 使う柱をしぼる：☰パネルの 📍 表示する柱をえらぶ で、授業で使う柱だけをえらびます。
  • 高さを強調：☰パネルの「高さを強調」で、デコボコを見やすくします（×3〜×5）。
  • 写真をつける：下の 📝 気づきメモ で、模型の上に写真つきのメモを置けます。
  • 3Dプリンターで印刷：☰パネルの 🧊 3Dプリンター用 で、模型を書き出せます。いま表示している柱状図の地点に、小さな赤い丸の印を付けられます（印の真下に、その柱状図の地層があります）。
  • 予想用のプリント：🔪 模型を切る →「切り口の色を消す」→ 🖨 印刷 で、色をぬって予想するワークシートが作れます。断面図の画面からも印刷できます。

7保存する・ほかの端末や子どもに配る

画面で作った場所と、読み込んだ柱状図は、その端末のブラウザの中だけに保存されます。ブラウザの履歴やデータを消すと消えます。ほかの端末や子どもの端末からは、そのままでは開けません。
したいこと方法
データを残しておく・別の端末に移す先生モードの データを書き出す → ファイルに保存。別の端末では、同じ学校名・緯度経度・半径で手順3をしてから、データを読み込む。
子どもの端末で開けるようにする書き出したファイルを、この模型を管理している横浜市 刀根息吹（ib00-tone@city.yokohama.lg.jp）まで送ってください。公開版に入れられます。公開版に入ると、入り口のページにカードとQRコードが出て、どの端末からでも開けます。
決まった画面を子どもに配る（公開版に入った後）先生モードの 🔗 子ども用リンク・送り先 → ①名前 ②見せる内容 ③ 📋 リンクをコピー（ロイロノート・Classroom へ）か 🖨 QRコードを印刷。
ほかの先生と画面を共有する👥 いまの画面を先生に共有。えらんだ柱は、受け取った先生の柱に足し合わされます。この端末で読み込んだ柱状図のデータと、画面で作った場所もリンクに入るので、受け取った先生の端末でもそのまま開けます。

8困ったとき

地形や地図が出ない・真っ白

インターネットにつながっているか確かめてください。学校のフィルタで国土地理院（cyberjapandata.gsi.go.jp）が止められていると出ません。少し待ってから開き直すと出ることもあります。

ボーリングの印が少ない・ない

半径を広げて（手順3で 1.5km〜2km）集め直してください。住宅地では、学校や道路・下水道の工事の資料が多いです。

「柱状図あつめ」を押しても何も起きない

国土地盤情報データベースで「閲覧」を押して地図が出ている画面で押してください。トップページでは動きません。

柱が地面からうき上がったり、うまったりして見える

資料をとった時と今とで、地面の高さが変わっている（土地を造成した）所があります。☰パネルの「柱の高さ」で今の地面にそろえるか、「資料と今の地図の高さが大きくずれた柱をかくす」で5m以上・10m以上ずれた柱を外せます。

地層の当てはめがおかしい

先生モードで柱をタップして開く画面の ✏️ 編集 で、1本ずつ直せます。子どもに見せる名前だけを変えたいときは、✏️ 仲間分けを決める を使います。

iPad で作りたい

手順1〜3と、手順4のA（1本ずつ）・手順5はiPadでもできます。ダウンロードしたXMLは「ファイル」アプリに入るので、読み込むときにそこからえらびます。

✉️ 問い合わせ・データの送り先

作った模型を公開版に入れたいとき、使い方で困ったときは、
横浜市 刀根息吹　ib00-tone@city.yokohama.lg.jp まで。

データを送るときは、先生モードの「データを書き出す」で作ったファイルと、学校名・模型の中心（緯度・経度）・半径を書いてください。

📚 出典・使い方のきまり

  • 地形・地図・航空写真・目印：国土地理院（地理院タイル）↗。模型の画面の下に出典を表示しています。
  • ボーリング柱状図：国土地盤情報データベース（国土地盤情報センター）↗。資料を使うときは出典を示すきまりがあるので、各柱の画面に出典を表示しています。
  • 地面の下の地層は、ボーリング資料をもとにした推定です。柱と柱の間は、実際とちがうことがあります。
